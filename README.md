# 🎤 **Проект «Выступления на TED-конференциях»**

Компания, получившая лицензию на проведение TED‑конференций, готовит 
своё первое мероприятие. Чтобы сохранить фирменный стиль TED и сделать 
событие по‑настоящему интересным, заказчик хочет опираться на статистику 
прошлых конференций. Для этого требуется разработать аналитический дашборд 
с ключевыми метриками выступлений.

🎯 **Цель проекта** - разработать дашборд, который поможет компании организовать 
мероприятие в духе классических конференций TED, учитывая опыт проведённых 
ранее конференций. 

Ссылка на дашборд: https://datalens.yandex/58vlvglv8saup

## ✅ **Что реализовано в дашборде**
- Общая статистика по данным: количество конференций, выступлений, 
спикеров и тегов.
- Детализация по конференциям:
	- средняя длительность выступлений;
	- максимальное количество просмотров;
	- суммарные аплодисменты;
	- количество спикеров.
- Анализ выступлений:
	- топ-10 самых смешных выступлений;
	- топ-20 популярных тегов.
- Спикеры: род деятельности самых «аплодируемых» спикеров.
- Возможность детализации: просмотр информации о каждом выступлении.
- Селекторы: страна, название конференции, теги, дата записи.

## 📚 **Источники информации**

В данном проекте использована база данных (БД) с информацией о выступлениях 
на TED-конференциях.

## 🛠️ **Инструменты и технологии**
- SQL — подготовка данных и агрегаций;
- Использованы JOIN, агрегатные функции, подзапросы;
- Yandex Datalens — визуализация данных и построение дашборда.

## 🏆 **Результат**
Создан интерактивный дашборд, позволяющий:
- находить популярные темы и успешных спикеров;
- оптимизировать тайминг и структуру конференции;
- планировать будущие мероприятия, учитывая предпочтения аудитории.

## 📁 **Используемые данные**
Проект разработан на основе базы данных, предоставленной **Яндекс Практикум** 
во время обучения. Все данные предоставлены исключительно в образовательных целях.
